# Documentation de l'instance nationale

Cette documentation decrit l'instance nationale ivoirienne d'OpenELIS Global,
telle qu'elle est deployee dans le cadre du programme LABQUASI II.

Elle est distincte de la documentation communautaire, publiee par le projet
d'origine et maintenue en anglais. Lorsqu'un sujet releve du socle commun et ne
presente aucune particularite nationale, cette documentation y renvoie plutot
que de le reproduire.

## Les quatre guides

| Guide                                    | A qui il s'adresse                                                    |
| ---------------------------------------- | --------------------------------------------------------------------- |
| Guide developpeur                        | Aux equipes qui compilent, font evoluer et maintiennent l'application |
| Guide d'installation et de deploiement   | Aux equipes qui installent un serveur central ou un site              |
| Guide d'administration et d'exploitation | Aux administrateurs d'instance et referents techniques de site        |
| Guide utilisateur                        | Aux agents de laboratoire, par profil et par parcours                 |

## Conventions de cette documentation

Les consignes de verification sont en italique et a l'imperatif. Les chemins de
menu sont en gras. Les commandes et les noms techniques sont en chasse fixe.

Les captures d'ecran sont realisees sur une instance de demonstration alimentee
en donnees fictives. Aucune donnee de patient reel n'y figure.
